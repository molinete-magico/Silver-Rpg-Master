# Silver RPG Master

Aplicação privada para apoio a sessões de RPG de mesa.

## Estado do projeto

Em desenvolvimento inicial. A auditoria confirmou que este repositório estava vazio antes do primeiro commit.

## Arquitetura planejada

- Astro + React + TypeScript
- Supabase (PostgreSQL, Auth, RLS e Realtime)
- Vercel
- LiveKit para compartilhamento de tela
- YouTube IFrame Player API para áudio incorporado

## Princípios

Confiabilidade, segurança, manutenção simples e interface focada no uso durante sessões reais. O sistema não é um VTT completo e não substitui o Discord para voz.

## Desenvolvimento

As instruções locais, variáveis de ambiente, arquitetura, migrations e procedimentos de implantação serão documentados conforme a implementação avançar.
